# Google Search Results Extractor (Selenium - Headless Mode)

This project uses **Selenium** in **headless mode** to perform automated Google searches and extract the top results. It's optimized to behave like a real user using Chrome options and custom user-agent.

---

## Features

- Headless Chrome (no GUI)
- Custom user-agent for stealth browsing
- Automated Google search
- Scrolls and extracts top 10 result titles
- Beginner-friendly structure

---

## Technologies Used

- Python
- Selenium WebDriver
- ChromeOptions

---

## How It Works

1. Launches Chrome in headless mode
2. Navigates to [google.com](https://www.google.com)
3. Inputs a search query
4. Scrolls the page to load results
5. Extracts the top result titles (h3 tags)
